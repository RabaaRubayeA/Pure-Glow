# Pure Glow 🌿

Pure Glow is a responsive skincare landing page designed to present skincare products in a clean, modern, and elegant interface.

The project was built as a frontend portfolio project with a focus on responsive design, semantic HTML, reusable CSS, and vanilla JavaScript DOM manipulation.

## ✨ Features

- Responsive design for mobile, tablet, and desktop screens
- Modern skincare-focused UI
- Dynamic product rendering using JavaScript
- Product data stored separately from the main JavaScript file
- Interactive product details modal
- Dynamic product information inside the modal
- Product ratings displayed dynamically
- WhatsApp ordering links with pre-filled product messages
- Newsletter subscription form
- Client-side email validation
- Interactive mobile navigation menu
- Hover effects and responsive layouts
- Accessible navigation controls

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- CSS Flexbox
- CSS Grid
- DOM Manipulation
- ES Modules
- Git & GitHub
- Netlify

## 📱 Responsive Design

The website was developed using a mobile-first approach and adapted for:

- Mobile devices
- Tablets
- Desktop screens

Responsive layouts are implemented using CSS media queries.
